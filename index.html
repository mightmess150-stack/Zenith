import math import os import re import subprocess import tempfile import threading import time import tkinter as tk from gtts import gTTS import ttkbootstrap as tb import torch from transformers import AutoModelForCausalLM, AutoTokenizer class MightXFullAI: def __init__(self, root): self.root = root self.root.title("MIGHT-X :: gTTS SPEECH & LOCAL AI") self.root.geometry("750x800") self.root.configure(bg="#05050d") self.state = "idle" # idle | thinking | speaking self.blink_state = False self._setup_ui() self.model_loaded = False self.tokenizer = None self.model = None self.device = "cuda" if torch.cuda.is_available() else "cpu" # تحميل النموذج بالخلفية threading.Thread(target=self._load_local_llm, daemon=True).start() self._start_animation_threads() def _setup_ui(self): self.title_lbl = tb.Label( self.root, text="MIGHT-X gTTS INTELLIGENCE", font=("Consolas", 18, "bold"), bootstyle="cyan", background="#05050d", ) self.title_lbl.pack(pady=10) self.canvas = tk.Canvas( self.root, width=400, height=400, bg="#05050d", highlightthickness=0, ) self.canvas.pack(pady=10) self.status_lbl = tb.Label( self.root, text="⏳ جاري تحميل المحرك بالذاكرة...", font=("Helvetica", 11), bootstyle="warning", background="#05050d", wraplength=650, justify="center", ) self.status_lbl.pack(pady=10) self.input_frame = tk.Frame(self.root, bg="#05050d") self.input_frame.pack(pady=10, fill="x", padx=30) self.entry = tb.Entry( self.input_frame, font=("Helvetica", 12), bootstyle="info" ) self.entry.pack(side="left", fill="x", expand=True, padx=5) self.entry.bind("", lambda e: self.send_message()) self.btn_send = tb.Button( self.input_frame, text="إرسال / Send", bootstyle="info-outline", command=self.send_message, state="disabled", ) self.btn_send.pack(side="right", padx=5) def _load_local_llm(self): model_name = "Qwen/Qwen2.5-1.5B-Instruct" try: self.tokenizer = AutoTokenizer.from_pretrained(model_name) torch_dtype = ( torch.float16 if self.device == "cuda" else torch.float32 ) self.model = AutoModelForCausalLM.from_pretrained( model_name, torch_dtype=torch_dtype, device_map="auto" if self.device == "cuda" else None, ) if self.device == "cpu": self.model.to("cpu") self.model_loaded = True self.root.after( 0, lambda: self.status_lbl.config( text=f"✅ MIGHT-X جاهز مع محرك gTTS على [{self.device.upper()}]!", bootstyle="success", ), ) self.root.after( 0, lambda: self.btn_send.config(state="normal") ) except Exception as e: self.root.after( 0, lambda: self.status_lbl.config( text=f"❌ خطأ تحميل النموذج: {e}", bootstyle="danger" ), ) def _start_animation_threads(self): threading.Thread(target=self._blinking_loop, daemon=True).start() self.animate_face() def _blinking_loop(self): while True: time.sleep(3.8) self.blink_state = True time.sleep(0.12) self.blink_state = False def send_message(self): if not self.model_loaded: return text = self.entry.get().strip() if not text: return self.entry.delete(0, tk.END) self.status_lbl.config(text=f"أنت: {text}", bootstyle="light") threading.Thread( target=self.generate_ai_response, args=(text,), daemon=True ).start() def generate_ai_response(self, user_text): self.state = "thinking" is_arabic = bool(re.search(r"[\u0600-\u06FF]", user_text)) system_instruction = ( "أنت MIGHT-X، مساعد ذكي. أجب باللغة العربية دائماً وباختصار شديد ومباشر." if is_arabic else "You are MIGHT-X. Reply in English very briefly and directly." ) messages = [ {"role": "system", "content": system_instruction}, {"role": "user", "content": user_text}, ] prompt = self.tokenizer.apply_chat_template( messages, tokenize=False, add_generation_prompt=True ) inputs = self.tokenizer([prompt], return_tensors="pt").to(self.device) with torch.no_grad(): outputs = self.model.generate( **inputs, max_new_tokens=90, temperature=0.6, do_sample=True, pad_token_id=self.tokenizer.eos_token_id, ) generated_ids = [ output_ids[len(input_ids) :] for input_ids, output_ids in zip(inputs.input_ids, outputs) ] response_text = self.tokenizer.batch_decode( generated_ids, skip_special_tokens=True )[0].strip() self.root.after( 0, lambda: self.status_lbl.config( text=f"MIGHT-X: {response_text}" ), ) self.state = "speaking" self.speak_with_gtts(response_text, is_arabic) self.state = "idle" def speak_with_gtts(self, text, is_arabic): """توليد الصوت بـ gTTS وتشغيله فوراً ثم حذف الملف المؤقت""" clean_text = text.replace("'", "").replace('"', "").replace("\n", " ") lang = "ar" if is_arabic else "en" temp_path = None try: # إنشاء ملف مؤقت with tempfile.NamedTemporaryFile(delete=False, suffix=".mp3") as fp: temp_path = fp.name # تحويل النص إلى صوت باستخدام gTTS tts = gTTS(text=clean_text, lang=lang, slow=False) tts.save(temp_path) # تشغيل الصوت المباشر عبر مشغل النظام ps_command = f""" $wm = New-Object -ComObject WMPlayer.OCX; $wm.URL = '{temp_path}'; $wm.controls.play(); Start-Sleep -MS 300; while ($wm.playState -eq 3 -or $wm.playState -eq 9) {{ Start-Sleep -MS 100 }} """ subprocess.run( ["powershell", "-Command", ps_command], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL, ) except Exception as e: print("gTTS Speech Error:", e) finally: # حذف الملف المؤقت فور الانتهاء تماماً if temp_path and os.path.exists(temp_path): try: os.remove(temp_path) except Exception: pass def animate_face(self): self.canvas.delete("all") cx, cy = 200, 200 color = "#00f0ff" if self.state == "idle" else "#00ffaa" if self.state == "thinking": color = "#ff2a6d" self.canvas.create_oval( cx - 100, cy - 140, cx + 100, cy + 120, outline=color, width=3 ) eye_y = cy - 25 l_eye_x, r_eye_x = cx - 40, cx + 40 if self.blink_state: self.canvas.create_line( l_eye_x - 15, eye_y, l_eye_x + 15, eye_y, fill=color, width=3 ) self.canvas.create_line( r_eye_x - 15, eye_y, r_eye_x + 15, eye_y, fill=color, width=3 ) else: self.canvas.create_oval( l_eye_x - 18, eye_y - 9, l_eye_x + 18, eye_y + 9, outline=color, width=2, ) self.canvas.create_oval( r_eye_x - 18, eye_y - 9, r_eye_x + 18, eye_y + 9, outline=color, width=2, ) self.canvas.create_oval( l_eye_x - 6, eye_y - 6, l_eye_x + 6, eye_y + 6, fill=color ) self.canvas.create_oval( r_eye_x - 6, eye_y - 6, r_eye_x + 6, eye_y + 6, fill=color ) self.canvas.create_line( l_eye_x - 20, eye_y - 20, l_eye_x + 15, eye_y - 24, fill=color, width=3, ) self.canvas.create_line( r_eye_x - 15, eye_y - 24, r_eye_x + 20, eye_y - 20, fill=color, width=3, ) self.canvas.create_line( cx, eye_y + 10, cx - 8, cy + 25, fill=color, width=2 ) self.canvas.create_line( cx - 8, cy + 25, cx + 5, cy + 25, fill=color, width=2 ) mouth_y = cy + 60 if self.state == "speaking": amplitude = abs(math.sin(time.time() * 18)) * 22 + 4 self.canvas.create_oval( cx - 28, mouth_y - (amplitude / 2), cx + 28, mouth_y + (amplitude / 2), outline=color, fill="#101020", width=3, ) else: self.canvas.create_line( cx - 28, mouth_y, cx + 28, mouth_y, fill=color, width=3 ) self.root.after(30, self.animate_face) if __name__ == "__main__": app = tb.Window(themename="darkly") might_x = MightXFullAI(app) app.mainloop()
